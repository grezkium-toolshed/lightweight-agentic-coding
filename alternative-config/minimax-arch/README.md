# MiniMax Alternative (Archived Reference)

This folder is retained as a reference for dedicated MiniMax experiments.

Active runtime in this repository is profile-driven from root scripts:

- `scripts/setup-config-device.sh --profile 128gb-minimax`
- `scripts/setup-config-device.ps1 -Profile 128gb-minimax`

The old `oh-my-opencode` flow is decommissioned and should not be used.

# Claude Code Templates

This directory contains guidance and starter files for using this lac setup with Claude Code.

Scope:
- docs and templates only
- no duplicated runtime launcher stack
- Anthropic-hosted models are the easiest supported path

Recommended use:
1. Keep llama.cpp + local Qwen profiles for local-first work via OpenCode.
2. Use Claude Code when teams want Anthropic-hosted models with lower setup friction.
3. Reuse the curated agent and skill ideas from this repo, but keep Claude-specific instructions in `CLAUDE.md`.
